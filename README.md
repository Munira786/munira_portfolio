# Munira Bhabarawala — Portfolio

Personal portfolio of **Munira Bhabarawala**, Software Engineer | React Developer.

A monochrome, pixel-type design with CSS-3D geometric visuals, built with:

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide icons

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
npm run preview  # serve the production build
```

## Editing content

All text (projects, experience, education, skills, links) lives in
[`src/config/site.ts`](src/config/site.ts). The resume PDF and favicon are in `public/`,
and the profile photo is `src/assets/munira.webp`.

## Deploy

The `dist/` folder is a static site — deploy it to Vercel, Netlify or GitHub Pages
(build command `npm run build`, output directory `dist`).
